# CSV Summarizer

Run the script:

Outputs JSON with row count, column names, and a sample.

Agent Skill Challenges

  • Operating environment: OS, shell, Python version, and installed packages vary
  • Tools available: Don't assume git, curl, uv, or network access exists
  • Permissions: Filesystem and command execution may be restricted
  • Design scripts to detect and report missing tools, and degrade gracefully

Why Python?

  • Ecosystem: Massive library support (HTTP requests, data parsing, etc.)
  • Readability: Easy for humans to maintain and agents to reason about
  • Portability: Simple packaging with `uv` or Docker
  • Standardization: Consistent error handling and CLI patterns

PEP 723 Inline Metadata

Use script headers to define dependencies without manual environment management.

# /// script
# requires-python = ">=3.11"
# dependencies = [
#     "requests",
#     "pandas"
# ]
# ///

import pandas as pd

Running with `uv`

Use uv to run scripts in ephemeral, managed environments.

# Run the script directly without management overhead:
uv run --no-project scripts/summarize.py --file data.csv

CLI Design: Argparse

Every skill should have a clear CLI interface.

import argparse

parser = argparse.ArgumentParser()
parser.add_argument("--file", required=True, help="Path to input file")
parser.add_argument("--format", choices=["json", "csv"], default="json")
args = parser.parse_args()

Config via Env Vars

Never hardcode secrets.

  • Good: os.environ.get("API_KEY")
  • Bad: API_KEY = "sk-12345..."
  • Use a `.env` file for local development, but never commit it to Git.

Output Contracts

  • stdout: Valid JSON only (the agent's primary input)
  • stderr: Logging and diagnostic information
  • Exit Codes: Use 0 for success, non-zero for failure.

Shared Helpers

Keep skills slim by utilizing a shared internal library or project structure.

from my_sdk.common import fetch_data, validate_schema

def main():
    raw = fetch_data()
    validate_schema(raw)
    print(json.dumps({"status": "success", "data": raw}))

Fail-Fast Error Handling

Be explicit about what went wrong.

  • Catch expected exceptions (ConnectionError, FileNotFoundError)
  • Provide human-readable error messages to stderr
  • Ensure the agent knows exactly why the tool failed.

Testing Strategy

  • Unit Tests: Test individual utility functions
  • Integration Tests: Run the script via uv run with dummy inputs
  • Mocking: Use Pytest mocks for API calls to avoid hitting real endpoints

Publishing & Distribution

  • Version your scripts using Git tags
  • Provide a clear setup.sh or requirements.txt if needed
  • Ensure the skill is "self-contained" enough to run in any clean environment

Anti-Patterns

  • Interactive prompts (the agent can't type)
  • Long-running operations without progress/feedback
  • Printing extra debug text to stdout
  • Hardcoded URLs or local file paths

Takeaways

  • Use PEP 621 / PEP 723 for deps.
  • Standardize on JSON stdout.
  • Keep scripts stateless and deterministic.
  • Design for the agent (clear help text, distinct errors).
